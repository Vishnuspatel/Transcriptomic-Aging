This project focused on predicting chronological age from gene expression data by reproducing the original machine learning models and developing new models, specifically neural networks and XGBoost. We also conducted additional research into genes and biological pathways associated with aging. The analysis involved data preprocessing, gene selection, log transformations, and principal component analysis (PCA) to reduce dimensionality and identify age-related patterns. We used leave-one-out cross-validation to evaluate model performance and compare errors across models. Additionally, our results showed that the influential genes were associated with extracellular matrix organization, skin structure, and cell cycle regulation.
